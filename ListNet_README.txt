This is the ListNet implementation. 


Instructions:

Please install PyTorch library to run the implementation.

Please open the ListNet Implementation folder itself in an IDE.


The listnet.py file contains the implementation of the algorithm.

The testing.py file can be run to obtain results which are stored in text files.

The testing_min_doc_sizes.py file is used to get results at NDCG@20 for queries associated with above ten documents.


In this file text documents showcasing results from a prior run of the algorithm are provided


The MQ2008 folder contains all data needed for the implementation
